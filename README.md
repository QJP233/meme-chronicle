# 抽象梗编年史 · Meme Chronicle

> Πάντα ῥεῖ — 万物皆流，梗亦如是。

2015–2026 中文互联网抽象梗与流行语全录。从斗鱼 6324 直播间的一声「抽象」，到算法与 AI 喂养下的全民共创——一部以「看不懂」为语言的十二年编年史。

## 内容

单文件 HTML 页面（`抽象梗编年史.html`），双击即可在浏览器打开，无需任何依赖。

- **12 个年份章节**（2015–2026），共 **168 个梗条目**
- 每条含：起源考据 · 释义 · 用法例句
- 附抽象文化起源考（6324 · 孙笑川 · 狗粉丝文化）
- 2025–2026 词条综合《咬文嚼字》与国家语言资源监测中心年度榜单核实

## 设计

- Claude / Hermes 风格的白底衬线编辑排版
- 古希腊元素：希腊回纹（meander）、爱奥尼柱式、希腊字母、赫拉克利特引言
- 纯白 × 爱琴海蓝双色调
- 字体：Noto Serif SC + Cormorant Garamond（需联网加载 Google Fonts，离线时回退系统衬线）
